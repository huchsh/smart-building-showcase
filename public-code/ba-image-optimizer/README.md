# BA 底圖批次最佳化工具

這是從實際維運工具整理的獨立展示版本。它批次處理 JPG、PNG、BMP、TIFF 圖檔，保留像素寬高，輸出到新資料夾並顯示每張圖的處理結果，不覆蓋原檔。

## 執行

需要 Python 3.9+ 與圖形桌面環境。

```powershell
python -m pip install -r requirements.txt
python ba_image_optimizer.py
```

選擇來源資料夾後，可設定 JPG 品質、是否將其他格式轉成 JPG，以及是否包含子資料夾。輸出在來源資料夾旁的 `原名稱_BA瘦身完成`。

## 現場使用流程

1. 先複製一組測試底圖到資料夾，選取該資料夾作為來源。
2. 設定是否轉成 JPG、品質及是否掃描子資料夾，再啟動批次處理。
3. 在視窗確認每張圖成功或失敗、原始與輸出檔案大小；到新資料夾抽查畫質與尺寸。
4. 確認看板仍可正常顯示後，再將輸出圖用於展示畫面。原始底圖保留，方便回復。

這是可在一般圖檔上重現的操作流程；是否真的縮小多少，取決於原圖格式與內容，不能用單一比例保證。

## 設計取捨

- PNG 保持 PNG 時使用無損壓縮；轉成 JPG 時透明區域會改成白色。
- JPG 重新編碼屬有損壓縮，可能有畫質差異；工具保證的是寬高不變，不保證像素完全相同。
- 原始圖不覆蓋；每張圖的成功或失敗會顯示於視窗。
- 檔案處理放在背景執行，畫面更新透過佇列回到主執行緒。
