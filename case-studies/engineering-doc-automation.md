# 工程文件與點位表自動整理

## 現場痛點

工程資料往往同時在 Word、Excel 與設備表中。人工把點位、Switch Port、模組 DI／DO 和 Gateway 對應重複抄到不同表格，容易漏列或填錯。

## 我做的處理

- Word 轉表工具讀取表格或 Tab 分隔段落，抽出觸發名稱與 `odata2` 對應，再輸出點位 Excel。
- 審查表產生程式根據規劃資料製作 Wiring、IP Device、Switch Port、Module Pin 與 Gateway Slave 等工作表，並處理系統配色、下拉選單與模組 DI／DO 規格比對。

## 交付物為什麼重要

點位表、接線表和交換器 Port 表各自正確還不夠，彼此也要能對照。這兩個小工具分別處理「從既有文件抽出結構化點位」和「由規劃資料產生審查表」。前者減少逐欄重打，後者讓相同來源生成多張工程表。若來源資料有誤，仍需工程師複核；程式不能代替現場確認。

審查一筆設備時，可沿著「設備 → 所屬系統 → Switch Port／模組接線 → Gateway 對應」查回規劃關係。
