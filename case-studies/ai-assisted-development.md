# AI 協作開發與工程問題解決

我從智慧建築和弱電案場的問題出發，定義需求、工程規則和操作情境，再用生成式 AI 協助開發及加速迭代。這種做法常被稱為 **Vibe Coding**；需求判斷和最終驗證由我負責。

## 我如何把問題變成工具

| 階段 | 我做的工作 | AI 協作的用途 |
|---|---|---|
| 釐清問題 | 找出資料散落、重複核對、操作易錯或難以追蹤的環節 | 協助整理流程與待確認條件 |
| 定義規則 | 把 PoE、Port、點位、資料欄位和操作流程轉成檢查條件 | 協助拆成程式模組、介面欄位和測試情境 |
| 快速開發 | 規劃 Python 或 Web 工具，先完成能操作的版本 | 產生或調整程式初稿、分析錯誤和改善介面 |
| 實際驗證 | 以工程資料、示範資料和操作流程檢查結果 | 協助定位失敗原因與規劃修正方向 |
| 持續改善 | 依測試結果調整、重測並補齊操作說明 | 加快重複修改，再由我確認功能結果 |

## 用在現有作品

- **弱電規劃器：**把 Port、PoE、上聯及 BA 規劃規則轉成互動配置和檢查流程。
- **BA 系統工具：**依 BA 點位、圖控及管理需求製作看板、需量管理、情境自動化和圖控建置工具。
- **導覽機平台：**從內容編輯、範本、素材管理延伸到發布版本和網頁播放器。
- **工程小工具：**包含 Modbus 模擬、能源與用水分析、文件轉表、圖片處理和批次最佳化。
